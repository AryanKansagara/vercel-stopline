03 / BEFORE YOU START

A little context.
A clearer first run.

What to bring, what gets saved, and how to interpret the result.

What do I need to try it?

A public HTTPS streaming URL on port 443. For OpenAI-compatible mode, supply your own compatible endpoint, model, prompt and API key. The service makes real requests when you start a profile.

What do the two policies do?

Propagate cancellation requests an upstream connection abort when the client disconnects. Keep observing continues reading, within a bounded run, so you can measure bytes that arrive after the disconnect.

Can it prove that model generation or billing stopped?

No. StopLine observes transport timing, bytes and connection closure at its proxy. It cannot see a provider’s internal computation, generated token count or billing. Browser chunks are not model tokens.

What is stored in my history?

Configuration metadata, timing, byte counts and connection events are saved in your private workspace. Response text, prompts and API keys are not retained in saved reports. Your browser holds the workspace access key.
